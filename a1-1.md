# Test Cases for File Upload Feature

The following test cases cover Functional Testing, Positive Testing, Negative Testing, Boundary Value Testing, Security Testing, and Error Handling for a File Upload feature.

## 1. Test assumptions

Assume the system has the following upload restrictions:

| Item              | Specification                |
| ----------------- | ---------------------------- |
| Supported formats | PDF, DOCX, JPG, PNG          |
| Maximum file size | 10 MB                        |
| Minimum file size | Greater than 0 bytes         |
| Upload method     | Select file and click Upload |
| Multiple uploads  | Not supported                |
| Duplicate files   | Allowed                      |

## 2. Test cases

15 Test Cases

| Test Case ID | Test Scenario                                      | Test Data / Steps                                      | Expected Result                                                              |
| ------------ | -------------------------------------------------- | ------------------------------------------------------ | ---------------------------------------------------------------------------- |
| TC-01        | Upload a valid PDF file                            | Select `document.pdf` (2 MB) and click Upload          | File uploads successfully and displays a success message.                    |
| TC-02        | Upload a valid DOCX file                           | Select `report.docx` (5 MB) and click Upload           | File uploads successfully.                                                   |
| TC-03        | Upload a valid image file                          | Select `image.jpg` (3 MB) and click Upload             | File uploads successfully.                                                   |
| TC-04        | Upload a PNG file                                  | Select `photo.png` (1 MB) and click Upload             | File uploads successfully.                                                   |
| TC-05        | Upload a file without selecting one                | Click Upload without selecting a file                  | System displays a validation message requesting a file.                      |
| TC-06        | Upload an unsupported file format                  | Select `video.mp4`                                     | System rejects the file and displays an unsupported format message.          |
| TC-07        | Upload a file exceeding the size limit             | Select a PDF file of 15 MB                             | System rejects the file and displays a maximum file size error.              |
| TC-08        | Upload a file at the maximum size                  | Select a PDF file of exactly 10 MB                     | File uploads successfully.                                                   |
| TC-09        | Upload an empty file                               | Select a file of 0 bytes                               | System rejects the file and displays an appropriate error message.           |
| TC-10        | Upload a file with a special character in its name | Select `my_report@2026!.pdf`                           | System handles the filename safely and uploads successfully.                 |
| TC-11        | Upload a duplicate file                            | Upload the same PDF file twice                         | System follows the duplicate-file policy without unexpected errors.          |
| TC-12        | Upload a corrupted file                            | Select a corrupted PDF file                            | System rejects the corrupted file or displays an appropriate error.          |
| TC-13        | Interrupt the upload process                       | Disconnect the network during upload                   | System displays an upload failure message and does not report false success. |
| TC-14        | Upload a file with a misleading extension          | Rename an executable file to `document.pdf`            | System detects the actual file type and rejects the file.                    |
| TC-15        | Upload a malicious file                            | Select a file containing potentially malicious content | System blocks the file according to its security policy.                     |

## 3. Test scenarios by testing type

| Testing Type           | Test Case IDs         | Purpose                                                     |
| ---------------------- | --------------------- | ----------------------------------------------------------- |
| Positive Testing       | TC-01 to TC-04        | Verify valid files can be uploaded.                         |
| Negative Testing       | TC-05 to TC-07, TC-09 | Verify invalid inputs are rejected.                         |
| Boundary Value Testing | TC-08                 | Verify the maximum file size boundary.                      |
| Filename Validation    | TC-10                 | Verify special characters are handled correctly.            |
| Duplicate Testing      | TC-11                 | Verify duplicate upload behavior.                           |
| Error Handling         | TC-12, TC-13          | Verify corrupted files and interrupted uploads are handled. |
| Security Testing       | TC-14, TC-15          | Verify file type validation and malicious file protection.  |

## 4. Additional important test cases

For more comprehensive software testing, consider these additional scenarios:

1. TC-16: Upload multiple files simultaneously – Verify whether the system correctly handles multiple file selections.
2. TC-17: Cancel an upload – Verify that users can cancel an upload before completion.
3. TC-18: Refresh the page during upload – Verify that the system handles page refresh without corrupting upload status.
4. TC-19: Upload the same file after deletion – Verify that a previously deleted file can be uploaded again.
5. TC-20: Verify uploaded file integrity – Download the uploaded file and compare it with the original file.
